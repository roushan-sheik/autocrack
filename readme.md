ধাপ ৩: টুলটি বিল্ড করা
টার্মিনালে নিচের কমান্ড দিন:

bash

go build -o autocrack
এরপর ls দিলে দেখবেন autocrack নামে একটি এক্সিকিউটেবল ফাইল তৈরি হয়েছে।

ধাপ ৪: টুলটি ব্যবহার করার নিয়ম
এখন থেকে আপনাকে আর কোনো কমান্ড মুখস্থ রাখতে হবে না বা টাইপ করতে হবে না। শুধু টার্মিনালে নিচের কমান্ডটি দিবেন:

bash

sudo ./autocrack
যেভাবে কাজ করবে:
১. টুলটি প্রথমে আপনার ওয়াইফাই ইন্টারফেসের নাম জিজ্ঞেস করবে (যেমন: wlp1s0 লিখে এন্টার দিন)।
২. এটি অটোমেটিক মনিটর মোডে চলে যাবে এবং ১৫ সেকেন্ড স্ক্যান করবে।
৩. স্ক্যান শেষে আপনার চারপাশের সব ওয়াইফাইয়ের লিস্ট নাম্বার দিয়ে দেখাবে।
৪. আপনি যে ওয়াইফাইটি ক্র্যাক করতে চান, তার নাম্বারটি লিখে এন্টার দিবেন (যেমন: 1)।
৫. এরপর টুলটি অটোমেটিক সেই ওয়াইফাইয়ের প্যাকেট ক্যাপচার শুরু করবে এবং ডিসকানেক্ট (Deauth) অ্যাটাক চালাবে।
৬. হ্যান্ডশেক ক্যাপচার হওয়ার পর অটোমেটিক rockyou.txt দিয়ে পাসওয়ার্ড বের করা শুরু করবে।
